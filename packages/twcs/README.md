# twcs

Short alias for **[tw-color-shades](https://www.npmjs.com/package/tw-color-shades)**.

```bash
npx twcs "#3498db"
```

This package contains no logic of its own — it re-exports the `tw-color-shades`
CLI under a shorter name, so the command works without a local install.

See the [main README](https://github.com/mbparvezme/tw-color-shades#readme) for
all options.
